# Controle de Vendas Mensais

Projeto desenvolvido em C como prática de programação estruturada, baseado em um exercício da disciplina de Algoritmos e Lógica de Programação da FATEC.

## Funcionalidades

- Cadastro de 12 vendedores
- Cálculo da comissão de cada vendedor
- Cálculo do faturamento por setor
- Cálculo do faturamento total da loja
- Quantidade de vendedores que não atingiram a meta

## Tecnologias

- Linguagem C


## Conceitos praticados

- Struct (Registro)
- Vetores
- Funções
- Laços de repetição
- Estruturas condicionais
- Organização do código em múltiplos arquivos
