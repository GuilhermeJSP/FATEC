#Jogo de Par ou Ímpar em C

Projeto desenvolvido em C como prática de programação estruturada, baseado em um exercício da disciplina de Algoritmos e Lógica de Programação.

##Funcionalidades
- Cadastro de dois jogadores
- Escolha entre par ou ímpar
- Entrada de números pelos jogadores
- Cálculo da soma dos valores
- Verificação automática do vencedor
- Possibilidade de jogar várias rodadas

##Tecnologias
- Linguagem C

##Conceitos praticados
- Estruturas condicionais (if/else)
- Laços de repetição (while)
- Manipulação de strings (char[], strcpy)
- Entrada e saída de dados (scanf e printf)
- Função principal (main)
- Lógica de paridade (módulo %)
